# 🦷 Dental Tools E-Commerce Website
A complete and modern dental equipment e-commerce website developed using **Django MVT architecture** for the backend and a responsive frontend built with **HTML, CSS, and JavaScript**.
This project focuses mainly on backend development and business logic implementation. The frontend design is based on customized and ready made templates that were heavily modified and improved to match the needs of the platform.
‼️ NOTE : All information saved in database are just for examples and completely fake.

‼️ NOTE : The language of the website is completely in Persian.

## 🚀 Features

* 🔍 Product search system
* 🛒 Full shopping cart and checkout functionality
* 📦 Order registration and order tracking system
* 📑 Product categorization
* 🏷️ Brand categorization and filtering
* 👀 Browse and view all products
* 👤 User registration, login, and logout system
* 🔐 Authentication and access-level based authorization
* 🧑‍💼 Separate access system for customers and administrators
* 📄 About Us page
* 👨‍💻 Dedicated user account dashboard

## 🛠️ Admin Panel Features
Administrators have access to an advanced management system with higher-level permissions, including:

* 📊 Viewing all users, products, and orders
* ✏️ Editing and deleting website data
* 🧾 Managing store information
* 🔑 Direct access to the Django administration panel
* 📈 Monitoring customer activities and orders

Customer and admin dashboards are slightly different based on user roles and permissions.

## 💻 Technologies Used

* 🐍 Django (MVT Architecture)
* 🎨 HTML
* 🎨 CSS
* ⚡ JavaScript
* 🗄️ SQLite / Django ORM

## 🎯 Project Goal

The main goal of this project was to build a fully functional and scalable e-commerce platform while focusing on backend development, authentication systems, database management, and user role handling using Django.
